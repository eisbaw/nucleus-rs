### Schema deviation from cycle-54 spec

Spec said `phase_times_ms: {build, run, diff}`. The actual Timings struct in the harness is `{compile, build, run}` (no separate `diff` phase — diff timing is rolled into the `Run` phase failure path). Emitted JSON matches the actual struct so consumers don't get a `null` field for a phase that does not exist in the source.
