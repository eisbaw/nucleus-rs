The symbolic verdict must be proven equivalent to the expanded replay on the class it claims, via an A/B harness. Shapes the symbolic argument does not cover must fall back LOUDLY (NUC_TRACE diagnostic) to the expanded replay — never a silent optimistic accept.

Pointers: gate = check_net_sound / check_bounded / check_deadlock_free in the compiler crate; the buffer-free structural walk from TASK-0453.04 is the pattern to extend; acfg_to_petri owns the expansion.
