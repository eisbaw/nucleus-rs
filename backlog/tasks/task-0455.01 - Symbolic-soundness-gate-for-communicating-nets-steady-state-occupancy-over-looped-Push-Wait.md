## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Successor to TASK-0453.04 (symbolic fast path, Done — but buffer-free subclass only). Today ANY schedule with a cross-worker transfer falls back to the expanded single-order replay: the net carries ~2 nodes per kernel firing, and the distributed matmul OOMs around 25GB RSS at N=512 (measured in TASK-0453 cycle 6). This is the keystone wall: it blocks compiling exactly the decompositions production needs, and it transitively blocks the runtime perf study (thesis sec:fw-quant states the coupling explicitly).

Work: prove boundedness + deadlock-freedom of the looped Push/Wait structure symbolically from the rolled ACFG — a steady-state occupancy argument per shared buffer place (peak occupancy across one loop period never exceeds capacity; the periodic schedule admits no stall) — without building the expansion.

Soundness discipline (non-negotiable, from thesis sec:fw-quant): do NOT approximate. An imprecise buffer analysis could ACCEPT a net the expanded replay would REJECT, trading soundness for scaling, which the gate exists to forbid. The symbolic verdict must be proven equivalent to the expanded replay on the class it claims, via an A/B harness. Shapes the symbolic argument does not cover must fall back LOUDLY (NUC_TRACE diagnostic) to the expanded replay — never a silent optimistic accept.

Pointers: gate = check_net_sound / check_bounded / check_deadlock_free in the compiler crate; the buffer-free structural walk from TASK-0453.04 is the pattern to extend; acfg_to_petri owns the expansion.
