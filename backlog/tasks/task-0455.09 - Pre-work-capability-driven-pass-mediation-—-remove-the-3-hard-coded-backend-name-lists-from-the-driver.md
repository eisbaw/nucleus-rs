From the 2026-06-09 architecture review (Risk 4, verified verbatim at the first site). Which compiler passes run is decided by string-matching backend names in the driver: driver/src/main.rs:400-404 (host-mediation gate: mp-tcp-bufsync|mp-tcp-event|mp-tcp-poll|mp-uds-event), :467 (host data-relay gate: mp-tcp-event|mp-uds-event), :639 (safe push reorder gate: mp-tcp-event|mp-uds-event). Every new platform must remember up to three lists; a miss is ContractGap at best, silent topology mismatch at worst — the silent-sibling class. Must land before TASK-0455.02 (embedded multi-MCU is the next topology) and before any new backend.

Work: extend the capabilities schema (docs/capabilities-toml.md + validator) with the topology/mediation flags; drive all three gates from the loaded capabilities; delete the name lists. Discipline: driver must mirror backend election EXACTLY (standing memory feedback-driver-must-mirror-backend-election-exactly — the host_election helper precedent). Fold in the adjacent waste the review found: the driver re-projects the ACFG up to three extra times for host election (main.rs:420, 473, 645) — collapse to one projection per build. Acceptable intermediate step: a single const table beside the capability load, then the full schema migration.
