## Goal

The cycle-195 mp-tcp-poll multi_worker_emit oracle (tests/multi_worker_emit.rs) covers 02-split-add/split and 06-separable-filter/distributed2. Neither exercises the host-excluding-barrier shape (workers={w0,w1,w2,w3} without host) that the cycle-195 driver-gate widening of apply_host_mediation_inject targets.

03-reduction/distributed IS a promoted [[required]] cell so the e2e gate verifies bit-identicality. But the cheaper/faster emit-string oracle has a coverage hole exactly on the headline mediation-shape this cycle's driver change addresses.

## Scope

Add a 3rd test (`reduction_03_distributed_poll_equiv_bufsync`) in tests/multi_worker_emit.rs that:

1. Lowers 03-reduction/distributed via the explicit pass-sequence pattern from `separable_filter_06_distributed2_poll_equiv_bufsync` (parse → lower → link → build_acfg → block_transforms → partition_workers → halo_inference → reuse_inference → inject_syncs → inject_transfers).

3. Optionally also applies `inject_check_frames` if it would surface a difference between the two backends (verify empirically).
4. Asserts byte-identicality (after the cycle-195 swap canonicalisation) of mp-tcp-poll vs mp-tcp-bufsync per-worker bins.

## Implementation Plan + EMPIRICAL FINDING (premise correction)

EMPIRICAL FINDING (verified by throwaway probe tests, since reverted):
03-reduction/distributed is NOT host-excluding. Via the full explicit
pass sequence (parse..inject_transfers), it produces exactly 2 barriers
SyncTag(0)/SyncTag(1), BOTH with participants {0,1,2,3,4} (host=WorkerId(0)
INCLUDED). apply_host_mediation_inject is a COMPLETE NO-OP on this ACFG
(host already a participant in every barrier): unmediated and mediated
ACFGs are byte-identical and emit byte-identical poll bins (host.rs has 8
barrier_cross_poll in BOTH). Therefore AC#2 as written (assert a
barrier_cross_poll on host's bin that is NOT present in the unmediated
ACFG) is UNSATISFIABLE on 03-reduction/distributed — mediation adds nothing.

RETARGET DECISION: target 15-transpose/distributed-rows. It is the only
schedule that is BOTH genuinely host-excluding AND a promoted [[required]]
cell on mp-tcp-poll. Verified shape: 4 barriers, SyncTag(2) participants
{1,2,3,4} (host-excluding). On this cell mediation is LOAD-BEARING:
  - UNMEDIATED mp_tcp_poll::emit returns Err(ContractGap("barrier #2
    participants {w1..w4} exclude the host worker; ... requires host as
    the barrier hub ... The driver's apply_host_mediation_inject pass
    adds host ...")) — it cannot even emit.
  - After apply_host_mediation_inject: emit SUCCEEDS; host.rs carries 16
    barrier_cross_poll calls (host now a participant in barrier #2 too),
    w0..w3 carry 4 each; 5 bins both poll and bufsync.

This is STRONGER than the original AC#2 intent: the unmediated path
doesn't just "lack" a host barrier_cross_poll, it FAILS to emit, proving
the mediation pass is necessary, not cosmetic.

REVISED AC#2 assertion (premise-correct): the test asserts (a) UNMEDIATED
mp_tcp_poll::emit on the host-excluding ACFG returns Err (ContractGap on
the host-excluding barrier), and (b) after apply_host_mediation_inject the
emit succeeds and host's bin carries a barrier_cross_poll for the formerly
host-excluding barrier. Then asserts poll==bufsync per-bin after the
cycle-195 swap canonicalisation.

DRIVER MIRROR (important): the mp-tcp-poll driver gate applies
apply_host_mediation_inject but NOT apply_host_data_relay_inject (that
relay pass is mp-tcp-event / mp-uds-event only — see driver/src/main.rs
line ~592). So this poll test applies ONLY apply_host_mediation_inject,
unlike the mp-uds-event sibling test which also calls the data relay.
inject_check_frames: 15-transpose/distributed-rows has no `check loop`
directive, so it is omitted (verified: adding it would be a no-op).

PLAN:
1. Add 3rd test transpose_15_distributed_rows_poll_equiv_bufsync in
   backends/mp-tcp-poll/tests/multi_worker_emit.rs mirroring
   separable_filter_06_distributed2_poll_equiv_bufsync's pass sequence.
2. Inline apply_host_mediation_inject (host via
   backend_common::elect_host_from_name_workers) after inject_transfers.
3. Assert unmediated emit Err + mediated host barrier_cross_poll + poll==
   bufsync per-bin canonicalised equivalence.
4. Full gate; test count +1, e2e unchanged.
