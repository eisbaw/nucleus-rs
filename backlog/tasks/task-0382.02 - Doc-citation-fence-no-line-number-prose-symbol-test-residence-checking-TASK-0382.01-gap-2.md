Catching it mechanically needs symbol/test-name RESIDENCE checking (does the named test/fn still live in the cited basename, crate-scoped?), NOT a line-count range check. Design carefully (e.g. restrict to the back-tick-quoted-ident + "in <base>.rs" co-occurrence shape, crate-scope the residence grep, SKIP on any ambiguity) or keep deferred.
