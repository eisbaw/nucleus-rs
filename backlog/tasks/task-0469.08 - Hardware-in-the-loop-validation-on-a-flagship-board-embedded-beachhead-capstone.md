## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The embedded-beachhead capstone. The thesis and PRD treat HIL as a stretch goal: tier-3 is validated under Renode co-simulation, which is not silicon (a co-simulated MCU is not silicon, a named residual in ch10). For the embedded firmware engineer to PREFER Nuc, at least one example must be shown byte-exact on real hardware, closing the gap between emulated and physical that no amount of Renode can. Take one flagship board (e.g. a Nucleo-H7 matching the STM32H7 reference shim), flash a generated bare-metal binary for a representative example (01-elementwise-add or 05-stencil single-worker, then a 2-MCU wiring if a second board + interconnect exists), capture output over UART, and diff against the same frozen reference the hosted tiers use. Validates timing-sensitive paths Renode does not model accurately (the trait wfi/timing hooks the co-sim cannot exercise, per ch7/ch10). Extends TASK-0048 (whose title carries HIL but defers it). Hardware-dependent and self-hosted-runner-dependent: mark env-blocked until a board on a runner exists; this is the marker task for that work.
