## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Land the surface syntax + AST node + parser for the bounded early-exit loop, INERT: parsed and represented but REJECTED at the ACFG-build boundary with a typed error pointing at the epic (acfg/build.rs NonConstLoopBound neighbourhood). Surface form (architect-preferred, design review cycle-254): for IDENT : 0 .. N until COND { Stmt* } where N is the COMPILE-TIME cap (keeps the loop statically bounded — the cap keystone) and COND is the HALT predicate (converged), e.g. until diff <= tol. Architect chose until over while: COND-as-halt reads as author intent, and while carries unbounded-loop baggage that invites misreading the cap as not-a-real-bound. Grammar ForStmt ::= for Ident : ConstExpr .. ConstExpr (until Expr)? { Stmt* } is LL(1)-clean (until/brace is single-token lookahead). The loop var IDENT MUST stay (double-buffering needs it for generation indexing) — this is why a pure while/iterate form was rejected. Depends on S2 (relational/bool ops) so COND is grammatical. First landed example uses a COND that does NOT need a scalar reduction (decouple from S3) — e.g. a pre-existing scalar predicate — proving the loop-control surface independently. Anchor a malformed-COND diagnostic at the until token (TASK-0434 VAR-anchoring precedent) to avoid reintroducing the diffuse-span problem. Inert => zero e2e change; 16-jacobi converge example stays SKIPPED with a precise reason.
