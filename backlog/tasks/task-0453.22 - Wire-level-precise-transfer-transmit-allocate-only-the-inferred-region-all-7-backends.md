## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The REAL comms-reduction work behind P2, separated out after the cycle-2 finding (TASK-0453.02). The transfer INFERENCE already computes a precise per-worker tile (partition.rs compute_partition_bounds_with_dim_prefix), but every backend Push emits {name}.clone() (WHOLE array; event_walker.rs:469) and every worker allocates the array full-shaped (vec![0; N]); the tile is consumed ONLY by receiver-side paste (wait.rs). So neither wire volume nor per-worker memory is reduced today, in affine OR non-affine cases. To actually cut communication: slice the Push source by the producer-side tile (band-shaped payload) AND have each receiver paste a band-shaped recv into a (band-shaped or full-shaped) buffer, coordinated across ALL 7 tier-1 backends + tier-2/3. RISK: the all-zero/wrong-bytes axis-mapping failure class; must stay byte-identical (differential rig) and keep the soundness gate verdict (gate counts tokens not bytes, so structurally safe, but message/marking must be re-validated). LARGE, cross-cutting; own multi-step project, NOT a single ping-pong. Quantify reduction (e.g. matmul blocks2d b: whole K*N -> column band per worker).
