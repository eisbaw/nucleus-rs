   (c) panic-vs-log-vs-count trade-offs:

Multi-worker mp-tcp-bufsync: PROCESS-LOCAL (one line per worker process — TASK-0052.05 note). std::process::exit() skips Drop ⇒ count summary lost (not used in generated code today, but a future codegen calling exit() would lose the count).
