## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The embedded-pattern capability matrix caps at sync / buffer=1 / blocking (thesis tab:capabilities), so the headline contribution — IO semantics as swappable schedule directives — is unrealized on the tier that motivated it (the 2013 ISP-firmware double-buffered DMA pipelines). Async double-buffering matters MOST on bare metal, where there is no OS to absorb latency.

Work: extend embedded-pattern + the shim trait to advertise and honor async, buffer=2 (DMA descriptor ring), notify=event (IRQ completion): a Push becomes a DMA descriptor enqueue with completion tracked by IRQ; a Wait becomes an IRQ-driven completion; pipeline=D initial markings honored on the embedded path. Validate in Renode on both committed shim families where the simulator model supports it (STM32H7 USART+DMA; nRF52840 UARTE EasyDMA), byte-exact against the same frozen references.

Capability-resolution both ways: a newly-accepted async schedule must actually run; a still-unsupported demand must still be rejected loudly naming the missing capability.

References: TASK-0048.13 (zero-copy DMA placement — complementary, not subsumed), 22-dma-pio-demo (per-edge mode=dma|pio hints), TASK-0048.11 (Renode DMA-USART de-risk spike, Done), staged boot-order machinery (TASK-0049.05.03). Renode env is NOT blocked here (memory: project-renode-env-not-blocked).

Two findings to absorb at design time: (1) the DMA arm today is a modelled arm+spin, explicitly synchronous (embedded-pattern render.rs ~390-421); buffer=2 needs split-phase emit (arm i+1 while i in flight) that the atomic Push event cannot express — expect the renderer to carry it as software pipelining within the loop body, not a new event variant. (2) Decide the Region story here: Alloc/Free events + Region are dead contract surface (never emitted, petri_to_events.rs:113-121; all 10 capabilities declare memory_regions=[heap] only; place_data parsed+capability-checked then discarded, capabilities.rs:432-439). Embedded TCM/SRAM placement is the first real consumer — choose Alloc-events vs sidecar lowering, or delete the variants (opacity-gate-rot discipline).
