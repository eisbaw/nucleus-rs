Follow-up to TASK-0048.01 (which proved the EMISSION pipeline with zero-filled stub inputs => deterministic ASCII line 'NUC-EX1 len=1024 checksum=0'). This task makes the generated STM32H7 firmware compute on REAL input data and stream the actual result for a binary diff vs reference.bin. Two pieces: (1) a real input path — the load_input/load_input_b effectful hooks currently no-op (alloc_in_region returns null, dma_wait no-ops), so a/b stay zero; needs either a Renode-injected input region (sysbus WriteBytes / a memory file backend) or embedding input.bin bytes into the firmware. (2) stream the raw output bytes (or a strengthened framing) over USART1 and binary-diff the captured bytes against reference.bin (replace the grep-q ASCII assertion with a byte-exact diff), per PRD §10.3 point 3. Note the carried Renode caveat: STM32F7_USART hardwires TXE=true so raw streaming is fine but back-pressure is unvalidated.
