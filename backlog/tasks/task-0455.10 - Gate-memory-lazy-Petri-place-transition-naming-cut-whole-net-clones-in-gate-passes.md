## Implementation Notes

WAVE-2 RESULT (left In Progress for the batched gate per ground rules).

== AC#2 DONE: whole-net clones eliminated, behaviour-neutral ==
Cut all FIVE net.clone() sites in the gate passes. They each did "let mut sim = net.clone(); sim.reset_to_initial();" then ONLY ever mutated sim.current_marking via fire_in_place — never places/transitions/arcs/initial_marking. Replaced with replay on a BORROWED &net + an owned Marking (cloned from net.initial_marking, the same source reset_to_initial copies in).
Mechanism: extracted petri::Net::fire_marking(&self, t, &mut Marking, &ArcIndex) — the borrow-friendly core (immutable net, only the passed marking mutated). fire_in_place is now a thin wrapper (mem::take current_marking, fire_marking, put back) so its public behaviour is unchanged.
Sites converted: boundedness.rs check_bounded (was :182) + derive_firing_order (was :335); deadlock.rs check_deadlock_free (was :230); net_soundness.rs BFS (was :480) + single-order fallback (was :630). Clone count per build is now ZERO whole-net clones (down from up to 5); only Marking clones remain.

== AC#3 MEASURED RSS (07-matmul, pthreads-sync, /usr/bin/time -v, 3 runs each) ==
distributed.sched.nuc:  baseline ~88.9 MB  -> post ~88.7 MB
distributed8.sched.nuc: baseline ~88.6 MB  -> post ~88.7 MB
HONEST FINDING: peak RSS is UNCHANGED at the largest currently-compiling N. The clones are ~4.2 MB each (computed: places~1.5MB + trans~0.19MB + arcs~1.05MB + 2 markings; distributed8 T=4149/A=65722) so up to ~21 MB of TRANSIENT churn was removed — but they overlap the gate phase and never set the high-water mark, which is dominated by the 10MB driver binary + backend codegen + allocator arenas. The win is reduced transient allocation + a smaller constant factor for the NeedsExpansion residual (much larger nets), NOT a peak-RSS drop at this N. Recorded straight rather than overclaimed.
