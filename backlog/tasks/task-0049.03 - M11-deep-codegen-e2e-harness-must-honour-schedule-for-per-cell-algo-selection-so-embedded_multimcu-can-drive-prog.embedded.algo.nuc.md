## Implementation Plan (implementer cycle 2026-05-29)

Add fn resolve_algo_path(sched_path: &std::path::Path) -> Result<PathBuf, String> in e2e/src/main.rs near the cell fns. Behaviour:
- fs::read_to_string(sched) -> propagate read err as Err(String).
- Scan lines for FIRST 'schedule for "<path>"' DIRECTIVE; trim leading ws; SKIP lines starting with '//' (the embedded scheds carry the literal 'schedule for' inside a // comment BEFORE the real directive — comment-skip trap).
- Extract substring between first and next '"' on the directive line.
- Resolve against sched_path.parent().join(extracted); do NOT canonicalize (matches today's '..'-bearing path behaviour).
- FAIL-LOUD: no directive / no closing quote -> Err('no schedule for ... directive in <path>').

Wire at BOTH hardcoded sites (run ~1286, determinism ~1766): reorder so 'sched' is built first, then 'let algo = resolve_algo_path(&sched)' with Err -> Failed{Compile} (run) / Skipped (determinism), mirroring the existing missing-fixture early-return shape. NO unwrap/expect/panic. Existing fixture-existence check then guards the resolved path.

Tests in e2e/src/tests.rs: (1) positive default '../prog.algo.nuc'; (2) comment-skip + non-default 'schedule for "WRONG"' in a // comment above real '../prog.embedded.algo.nuc' -> returns embedded path NOT WRONG; (3) fail-loud no directive.
