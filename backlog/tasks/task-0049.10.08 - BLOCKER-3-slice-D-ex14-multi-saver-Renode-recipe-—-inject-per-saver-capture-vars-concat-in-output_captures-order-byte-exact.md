All arrays are [i32;64]=256B so this is NOT a size mismatch (the existing TASK-0049.05.02 framing) — it is a seq-multiplex + push/recv-order-agreement defect on a shared FIFO link. The dsp<->rf hub similarly carries seq1 (dsp->rf) and seq3 (rf->dsp) bidirectionally on one hub.
