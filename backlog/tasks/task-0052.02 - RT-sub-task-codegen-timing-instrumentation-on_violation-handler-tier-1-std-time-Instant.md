## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
PRD §6.3.5: 'compiler injects measurement code at the loop iteration boundary and emits a comparison against the threshold'. Tier-1 uses std::time::Instant. Backend-agnostic codegen path: the EventList contract gets a new Event variant (CheckBegin/CheckEnd or a CheckLoopFrame block) OR the rolled-Event::Loop carries an optional check-frame annotation. Pick one, document, justify.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 pthreads-sync + mp-tcp-bufsync codegen: each check loop becomes Instant::now() at iter start + duration check at iter end vs the threshold ns; on_violation=panic emits panic! with loop_var + measured_ns + threshold_ns; on_violation=log emits eprintln! ; on_violation=count tallies and prints summary at run end.
- [ ] #2 Determinism preserved: the assertion machinery does NOT introduce non-determinism (no clock-based branching that changes output bytes; timing-violation panic terminates with a distinct exit code so xbackend differential is unambiguous).
- [ ] #3 Positive test: a fast kernel with a generous threshold runs clean. Negative test: a deliberately slow kernel (sleep) with a tight threshold panics on tier-1 sync backends; assertion error message includes both numbers and the loop_var.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Design: add optional check_frame: Option<CheckFrame> to Event::Loop (mirroring block_tag precedent). Implement via composable post-projection pass passes::inject_check_frames that joins sched_ir.checks (NAME-keyed) with acfg.name_iter_vars (NAME->IterVar). Codegen: pthreads-sync single-worker emit wraps loop body with std::time::Instant::now() + as_nanos() comparison + panic. Mirror on mp-tcp-bufsync. Multi-worker pthreads-sync rejects check_frame with typed error (no tier-1 cell exercises this combination today; tracked as TASK-0052.05). on_violation=log/count deferred to TASK-0052.04. Determinism preserved: success-path emitted bytes unchanged; panic exits rustc 101 + empty stdout (cross-backend differential treats as assertion signal).
<!-- SECTION:PLAN:END -->
