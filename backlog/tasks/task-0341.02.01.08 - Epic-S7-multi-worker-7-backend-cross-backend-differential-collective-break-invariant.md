## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Multi-worker convergence loop + cross-backend differential across all 7 tier-1 backends (TASK-0341.02.01 AC#3). P1 HARD INVARIANT (architect design review cycle-254): the break is a COLLECTIVE decision, NEVER a local one. Each worker computes a partial convergence over its partition; the GLOBAL convergence scalar is all-reduced at a barrier and broadcast, and EVERY worker branches on the IDENTICAL broadcast value — so all workers exit at the same iteration by construction (bit-identity holds; no nondeterministic deadlock). If instead each worker tested its LOCAL diff, worker A could break at iter 7 while worker B waits at the next barrier => deadlock. Reuse the existing barrier/SyncTag machinery for the all-reduce+broadcast. Add a NEGATIVE test that a local-only break predicate is REJECTED fail-loud. Interacts with the cumulative cross-iteration tracking and the host gather (the same place xN-correctness bit other distributed cumulative work — TASK-0366).
