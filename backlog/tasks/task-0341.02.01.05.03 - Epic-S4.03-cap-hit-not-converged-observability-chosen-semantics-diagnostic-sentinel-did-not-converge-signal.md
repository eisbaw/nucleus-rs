## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Cap-hit-not-converged must be observable. A for..until that runs the full N iterations without the COND ever firing reached the WORST-CASE cap, which is semantically distinct from converging early at k<N. A silent stop-at-N looks byte-identical to a converged run — exactly the silent-drop anti-pattern (feedback-option-none-skip-arm-silent-drop). Decide and pin the semantics: (a) a compiler/runtime diagnostic, (b) a sentinel value in the output, or (c) a recorded did-not-converge signal. Gated on .05.01 (the lowering must exist first).
<!-- SECTION:DESCRIPTION:END -->

- [ ] #2 Chosen semantics pinned (diagnostic emitted / sentinel value / recorded did-not-converge signal) + a test that distinguishes converged-at-k<N from hit-cap-N-not-converged
