## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Cap-hit-not-converged must be observable. A for..until that runs the full N iterations without the COND ever firing reached the WORST-CASE cap, which is semantically distinct from converging early at k<N. A silent stop-at-N looks byte-identical to a converged run — exactly the silent-drop anti-pattern (feedback-option-none-skip-arm-silent-drop). Decide and pin the semantics: (a) a compiler/runtime diagnostic, (b) a sentinel value in the output, or (c) a recorded did-not-converge signal. Gated on .05.01 (the lowering must exist first).
<!-- SECTION:DESCRIPTION:END -->

- [x] #2 Chosen semantics pinned (diagnostic emitted / sentinel value / recorded did-not-converge signal) + a test that distinguishes converged-at-k<N from hit-cap-N-not-converged

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Forward-carried from TASK-0341.02.01.05.04 (cycle-261, commit b8f7686): The runtime break now emits as `if <cond> { break; }` after the loop body in pthreads-sync. CAP-HIT-NOT-CONVERGED OBSERVABILITY (your AC) is NOT yet wired: today if the cap N is reached without the predicate ever firing, the loop simply exits at the for-range end with NO signal distinguishing converged-early from hit-the-cap. The break is a plain Rust `break;` with no post-loop did-not-converge flag/sentinel/diagnostic. Your slice must add the observable cap-hit signal AROUND/AFTER this break emit site (pthreads-sync render_event Loop arm, right after the `if <cond> { break; }` line / loop close). Watch feedback-option-none-skip-arm-silent-drop: a silent stop-at-N that looks identical to converged is exactly the defect to avoid.

DONE cycle-262 with parent TASK-0341.02.01.06 (commit ee5513b). CHOSEN SEMANTICS (AC#2): a runtime STDERR diagnostic. break_loop::emit_cap_hit_resolution emits, after the break loop: `if __nuc_break_gen < 0 { eprintln!("[[nuc_converge]] did NOT converge within the cap ..."); }` + `let __nuc_final_gen = if __nuc_break_gen < 0 { cap } else { __nuc_break_gen };`. AC#1 (observable, NOT silent stop): the -1 sentinel distinguishes cap-hit from a converged early-exit, and the stderr line announces it. Stderr (not stdout/output.bin) keeps the cross-backend differential success-path bytes untouched (determinism-safe; mirrors the check_frame Log precedent). On cap-hit __nuc_final_gen resolves to the cap (last computed generation) so a valid generation is still extracted, while STILL being observable. AC#2 test: cap_hit_resolution_distinguishes_converged_from_cap_hit asserts the sentinel branch + diagnostic + the converged-vs-cap-hit resolution. Watched feedback-option-none-skip-arm-silent-drop: a cap-hit does NOT look byte-identical to a converged run that would extract a different generation.
