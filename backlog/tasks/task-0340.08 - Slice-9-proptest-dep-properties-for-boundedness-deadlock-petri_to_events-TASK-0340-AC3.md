## Scope (per AC#3 + the parent task description)

**Generators emit small bounded ACFGs.** Not random graphs; ACFGs that resemble real compiler outputs (a few iter/synthesis Operations, a Place that's a small power-of-two cap, a transition that consumes-and-produces with a bounded balance). Random unstructured nets would trivially satisfy properties; meaningful generators borrow shapes from the existing 03/04/05 algorithm examples.

**Properties (at least 3 per pass = 9 total):**

passes/boundedness.rs:
- (b.1) **HEADLINE per parent task desc**: `check_bounded(net, firing_order)` agrees with explicit bounded-reachability enumeration up to N=50 firing steps. Two oracle disagreements at random inputs is a P1 defect.
- (b.2) **Determinism**: `check_bounded` on the same input returns the same Result every call (no HashMap iteration order seep).
- (b.3) **Accepts-iff-bounded**: `check_bounded` rejects iff the bounded-reachability oracle finds at least one reachable state where some place exceeds its capacity.

passes/deadlock.rs:
- (d.1) **HEADLINE**: `check_deadlock_free(net, firing_order)` agrees with explicit reachability-enumeration deadlock-check on the same generated nets (Petri-net deadlock = reachable state where no transition is enabled, with at least one transition that hasn't fired).
- (d.2) **Determinism**: same input → same result.
- (d.3) **Rejects-iff-reaches-dead-state**: `check_deadlock_free` rejects iff the oracle finds a reachable dead state.

passes/petri_to_events.rs:
- (p.1) **HEADLINE per parent task desc**: output is acyclic per worker (`acfg_to_events(acfg)[w]` is a topologically-orderable list of Events for every WorkerId).
- (p.2) **WorkerId coverage**: `acfg_to_events(acfg).keys()` matches the set of WorkerIds referenced in the input ACFG (no silent drops; no spurious workers added).
- (p.3) **Determinism**: same ACFG → same BTreeMap (since output uses BTreeMap, this should be free; pin it as a regression test).

## Generator design

- A `prop_compose!` generator for small Petri-nets directly (places + transitions + arcs + an initial marking; size capped at ~10 places / ~10 transitions to keep oracle enumeration tractable).
- A separate generator for small ACFGs (a small linear sequence of Operations, 1-4 IterVars with small bounds, 1-3 Data symbols; convertible via `acfg_to_petri::acfg_to_net`).
- Capacity bounds set as small NonZeroU32 (cap=1, cap=2, cap=3 are the sharp-edge cases).
- Avoid generating nets so large the oracle enumeration explodes — bound the proptest case count + the per-case state-space cap.

## Oracle implementations (the load-bearing part of this slice)

The `check_bounded` and `check_deadlock_free` oracles must be implemented IN THE TEST FILE (or a shared test-only `tests/common/proptest_oracles.rs`); they are NOT in the compiler library. They are intentionally INDEPENDENT implementations against which the pass under test is checked.

- **Bounded-reachability enumeration**: BFS over markings up to N=50 steps OR until state-space cap reached (e.g. 10_000 markings); flag overflow if cap hit (don't lie about an exhaustive search).
- **Deadlock enumeration**: same BFS + check for terminal states with un-fired transitions.

If the oracle hits its cap, the proptest case is INCONCLUSIVE — `prop_assume!` it away rather than passing it silently. This is the right honesty discipline.
