Forward-carried from TASK-0426 (silent-sibling sweep). NOTE from TASK-0426: the original ENOENT flake was NOT reproducible in 16 runs and static analysis did not confirm the documented shared-parent mechanism for unique-named subdirs in a single cargo-test process — so this sweep is defense-in-depth / consistency, not a confirmed-bug fix. If the flake recurs, capture the exact failing ABSOLUTE path + the two racing operations (e.g. via a logging wrapper or strace) to pin the true mechanism before assuming it is the scratch-dir pattern.
