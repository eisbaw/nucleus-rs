GOTCHAS / SUBTLETIES / REJECTED:
- HASH IMPL: IrExpr is NOT Hash (derives only Debug/Clone/PartialEq/Eq). The Event manual Hash hashes only break_cond.is_some() (a 1-byte discriminant), exactly as Range endpoints are hashed component-wise. Collisions on break-predicate-only-difference are acceptable (PartialEq stays exact and DOES compare the full IrExpr). break_cond is codegen-only so loops in dedup/HashSet paths (pre-codegen) never carry distinct predicates today.
- check_frame x break ORDERING: the break is emitted AFTER the body AND after any check_frame latency measurement closes (after the `if let Some(frame){...}else{...}` block, before the loop close brace). So the final break-causing iteration is fully executed and (if instrumented) measured before the loop terminates. Verified by a fire_pos<break_pos ordering assert in break_cond_codegen.
- TAGGED/STRIP-MINE path: break_cond is contractually None for tile loops (petri_to_events only sets it from the untagged SOURCE Repeat). The pthreads-sync strip-mine arm returns early with no break emit site, so a Some there is a projection bug -> fail-loud ContractGap guard added (panic-not-diagnostic discipline). Pinned by break_cond_some_on_block_tagged_loop_fails_loud.
- OPERAND RENDERER CHOICE: reused render_int_expr for the Compare operands (single source of truth for scalar-value rendering) rather than a new operand renderer. render_int_expr renders Ident->bare scalar var, IntLit->num, DataRef->gather load — exactly the runtime scalar-value shapes a convergence operand takes. Its Compare arm correctly rejects (a nested comparison is not a scalar value).
- SILENT-SIBLING sweep: ~13 Event::Loop literal/destructure sites compiler-forced. Production destructure-only arms in OTHER backends (multi_worker_walker event_walker, tcp_plan events) bound break_cond:_ with a comment (not ..-elided -> keeps the future-field silent-sibling guard); they never observe a Some (for..until not multi-worker-partitioned). embedded-pattern got a fail-loud reject (it IS single-worker but break emit is tier-1-only this slice).
