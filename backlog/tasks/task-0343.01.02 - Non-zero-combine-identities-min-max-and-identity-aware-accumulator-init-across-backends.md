## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Follow-up to TASK-0343.01.01 (which landed sum/or/xor — all share zero identity). min->identity MAX, max->identity MIN, and->identity all-ones each need the accumulator's pre-init to use the combine identity instead of the hardcoded zero. Init is rendered by render_array_init_for / rust_scalar_zero, DUPLICATED across backend-common render/types.rs + openmp-rs/multi_worker.rs + mpi_plan/plan.rs + pthreads-sync/multi_worker.rs, and is keyed by TYPE not by accumulator identity. So this task must thread 'this data symbol is a min/max/and accumulator -> init to its combine identity' to every init site (the per-backend private partial AND the host accumulator). Higher regression risk than the zero-identity slice because it touches the bit-identity-critical init path in all backends. AC: a distributed min or max reduction-to-array example, bit-identical across 7 tier-1 backends. Depends on TASK-0343.01.01.
