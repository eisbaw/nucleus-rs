## Description

TASK-0453.22 reduced WIRE volume and send-buffer sizing but NOT per-worker memory: the receiver still allocates the full-shaped destination Vec and pastes the narrowed payload into it. Reducing per-worker allocation to the owned band (+halo) is the unfinished footprint half of the original over-communication shortcoming (thesis sec:disc-shortcomings).

This is a deeper change than the wire flip: every downstream read of the destination array assumes full-shape indexing (kernel calls index with global coordinates), so band-shaped allocation needs either index rebasing at kernel-call render time or a banded view abstraction. Scope it honestly; it may interact with TASK-0455.03 (case study memory measurements).
