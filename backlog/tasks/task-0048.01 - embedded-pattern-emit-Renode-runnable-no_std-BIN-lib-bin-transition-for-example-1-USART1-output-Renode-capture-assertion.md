### Design decisions
- FLAG vs separate backend: chose --shim <name> (PRD §10.3 quad's target-shim). Forward-compatible for future shims. embedded-pattern + no --shim = M9 lib (unchanged); + --shim stm32h7 = M10 bin.
- UART framing: deterministic ASCII line 'NUC-EX1 len=<N> checksum=<sum>' (no_std u32->ASCII-decimal writer, no core::fmt). dma_push walks the drained bytes accumulating a wrapping additive checksum. Chose ASCII-line + grep-q over raw-byte streaming: raw null bytes are fragile to assert from a shell recipe; the checksum still changes if the stream/compute path corrupts a byte.
- no_std clock for check loop: DEFERRED (filed TASK-0048.04). The check_frame reject (shared lib+bin via render_run_body) now forward-links it.

### Gotchas / things the next slice would re-learn the hard way
- Renode STM32F7_USART hardwires TXE=true: the TX poll never waits, so back-pressure is UNVALIDATED here (fine — the poll is the correct pattern). But CR1=UE|TE enable IS load-bearing: the model DROPS bytes if TX is not enabled. (Carried+confirmed from the template.)
- memory.x RAM must stay <=128K (full DTCM @0x20000000); raising it silently overflows DTCM with NO linker error unless you map axiSram@0x24000000.
