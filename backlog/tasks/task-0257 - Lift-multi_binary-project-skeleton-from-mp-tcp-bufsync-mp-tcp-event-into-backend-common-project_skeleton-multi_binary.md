## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Architect-review F6 of TASK-0042.05 (cycle 79): mp-tcp-event's lib.rs:360-410 (render_cargo_toml + render_run_sh_single + wrap_single_worker for single-worker path) and multi_worker.rs:render_cargo_toml/render_run_sh are each near-byte-copies of mp-tcp-bufsync's homologous helpers. With mp-tcp-event Stage 3 landed, the duplication is now 3-way:
1. mp-tcp-bufsync (single source today).
2. mp-tcp-event single-worker (delegated single-binary).
3. mp-tcp-event multi-worker (multi-binary mio reactor variant).

backend-common already houses project_skeleton (single_binary). Add a sibling module project_skeleton::multi_binary with the multi-binary Cargo.toml + multi-binary run.sh (NUC_RENDEZVOUS_DIR setup + EXIT trap + per-worker launch loop) so both mp-tcp-* backends consume the same emit. Risk: any drift in the byte output of mp-tcp-bufsync would invalidate every cached SHA256 in e2e-matrix.toml — verify byte-identical re-emit before and after.

Acceptance:
1. project_skeleton::multi_binary { render_cargo_toml(bin_names), render_run_sh(workers, host) } exists in backend-common, parameterised so both backends consume.
2. mp-tcp-bufsync's inline render_run_sh + render_cargo_toml call the lift; emits byte-identical bytes (verify with a determinism-check round-trip).
3. mp-tcp-event single-worker + multi-worker arms call the lift; byte-identical to today.
4. just e2e 88/73/0/15/0 preserved (no required-fail regression).
5. just determinism-check PASS.
6. The 3-way duplication is removed; the only remaining cross-backend arrow is the deliberate render_single_worker_main delegation (semantic, not infra).

Estimated scope: ~500 LoC touch. Defer behind any work that mutates the multi-binary emit shape so the lift catches the new shape uniformly.

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Implementation:

1. New module backend_common::project_skeleton::multi_binary with three helpers:
   - render_cargo_toml(bin_names: &[String], extra_dependencies: Option<&str>) -> String
     - Emits Cargo.toml with one [[bin]] per bin_name pointing to src/bin/<name>.rs.
     - extra_dependencies = Some(deps_block) adds a [dependencies] section (mp-tcp-event needs mio = ...; mp-tcp-bufsync passes None).
     - Header: neutral 'Generated by the nucleus pre-compiler.' (TASK-0246 single_binary precedent).
   - render_run_sh_single() -> String
     - Single-process run.sh for the 0/1-worker fallback in both backends. Mirrors the current bytes modulo header → neutral.
   - render_run_sh_multi(host_name, non_host_names, so_buf_bytes, so_buf_comment_block) -> String
     - Multi-process run.sh. Host-first launch, EXIT trap on NUC_RENDEZVOUS_DIR, exports NUC_SO_BUF, host PID + non-host PIDs collected, wait + per-failure rc.
     - so_buf_comment_block: full per-backend comment text (sync=1 msg vs application-ring buffering). Preserved verbatim from each backend's current emit.

2. mp-tcp-bufsync (nucleus/backends/mp-tcp-bufsync/src/lib.rs):
   - Delete inline render_cargo_toml, render_run_sh_single, Plan::render_run_sh.
   - Replace each call site with backend_common::project_skeleton::multi_binary delegates.
   - SO_BUF comment block becomes a const string passed in.

3. mp-tcp-event (nucleus/backends/mp-tcp-event/src/lib.rs + multi_worker.rs):
   - Delete inline render_cargo_toml (lib.rs:375), render_run_sh_single (lib.rs:407).
   - Delete multi_worker::render_cargo_toml, multi_worker::render_run_sh.
   - Replace each call site with delegates. mp-tcp-event passes Some(mio_deps_str) for Cargo.toml.

4. Update doc-comments at the existing project_skeleton single_binary site to reference the new sibling.

5. Header text drift (intentional, follows TASK-0246 single_binary precedent):
   - Pre-lift: 'Generated by the mp-tcp-bufsync backend' / 'Generated by the mp-tcp-event backend'.
   - Post-lift: 'Generated by the nucleus pre-compiler'.
   - Runtime output bytes unchanged. Determinism preserved (both runs use the new bytes). e2e cell pass/fail unchanged (compares output.bin to reference.bin, not source bytes).

6. Tests:
   - 3-4 new unit tests in project_skeleton.rs (similar to existing single_binary tests): header byte-stable, [[bin]] count matches bin_names.len(), [dependencies] block conditionally emitted.
   - No new e2e tests; the existing determinism + e2e + cross-backend differential catch any structural regression.
