## Goal

Silent-sibling follow-up filed during TASK-0044.01.03 + TASK-0044.02.02.01
(cycle 231). Those two tasks closed the host-excluding-barrier oracle hole
for openmp-rs and mp-tcp-poll by retargeting from the (wrongly-premised)
03-reduction/distributed to 15-transpose/distributed-rows — the only
schedule that is BOTH genuinely host-excluding AND a promoted [[required]]
e2e cell on those backends.

The SAME hole exists in the two reactor backends:

- mp-tcp-event/tests/multi_worker_emit.rs: its cross-backend emit-
  equivalence oracle covers only 02-split-add (host-INCLUDED). It DOES
  have a separate Plan::build host-excluding-barrier REJECTION test, but
  via a synthetic hand-built ACFG, not a real promoted required cell, and
  with no post-mediation emit-equivalence assertion.
- mp-uds-event/tests/multi_worker_emit.rs: its inline-host_mediation
  06-distributed2 oracle runs apply_host_mediation_inject, but 06 is
  host-INCLUDED so the mediation is a NO-OP there (same vacuity the poll
  task hit on 03). No real host-excluding cell is exercised.

Both are [[required]] on 15-transpose/distributed-rows (all 7 tier-1
backends are). The mp-uds-event test already wires the exact inline
apply_host_mediation_inject + elect_host_from_name_workers pattern needed.

## Scope

1. mp-tcp-event: add a 15-transpose/distributed-rows oracle test that
   inline-applies apply_host_mediation_inject (the driver's event-backend
   gate ALSO applies apply_host_data_relay_inject — mirror BOTH, matching
   the existing mp-uds-event 06 test) and asserts mp-tcp-event ==
   structural-twin after canonicalisation, plus a host barrier_cross on
   the mediated barrier.
2. mp-uds-event: add the analogous 15-transpose/distributed-rows oracle
   (mirror the existing separable_filter_06_distributed2_uds_equiv_tcp,
   which already does mediation + data-relay).

## Honest scope

~50-60 LoC of test per backend; pattern is established by
TASK-0044.01.03 / TASK-0044.02.02.01 and the existing mp-uds-event 06
test. e2e remains the load-bearing bit-identicality oracle; these are
faster-feedback emit-string pins.

## Forward-carried empirical facts (verified cycle 231, probes reverted)

- 15-transpose/distributed-rows produces 4 barriers; SyncTag(2) has
  participants {w0,w1,w2,w3} (host-excluding). The other 3 include host.
- Unmediated mp-tcp-poll::emit on this ACFG returns
  Err(ContractGap("... exclude the host worker ...")). The reactor
  backends (mp-tcp-event / mp-uds-event) carry the SAME defensive
  host-excluding-barrier guard in Plan::build, so the same Err is
  expected pre-mediation — assert it.
- The event-backend driver gate applies apply_host_data_relay_inject
  (mp-tcp-event / mp-uds-event ONLY), in ADDITION to
  apply_host_mediation_inject; the poll/bufsync gate does NOT. Mirror the
  driver per-backend exactly.
