## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Scouting de-risk for M11 (TASK-0049), gathered while closing the M10 AC#1 de-risk (TASK-0048.11). VERIFIED from the bundled Renode 1.16.1 source + scripts (not yet empirically run with our own firmware): (A) Renode SUPPORTS multi-MCU co-simulation — multiple 'mach create' machines in one emulation; the bundled scripts/multi-node/imxrt500_nrf52840_pigweed_bt_advertiser.resc co-simulates two DIFFERENT MCU families (IMXRT500 + nRF52840) talking over a wired UART hub ('emulation CreateUARTHub'; 'connector Connect <uart> <hub>'). (B) The cross-machine WIRED interconnect models that exist (emulation Create* verbs): CreateUARTHub / CreateWordUARTHub / CreateDoubleWordUARTHub, CreateCANHub, CreateLINHub, CreateGPIOConnector, CreateUSBConnector (+ wireless CreateBLEMedium / CreateIEEE802_15_4Medium). UARTHubBase is IExternal+IConnectable (genuinely cross-machine). (C) CRITICAL GAP: there is NO SPIHub / SPIConnector / cross-machine SPI link ANYWHERE in the Renode source (exhaustive grep empty). Renode SPI is INTRA-machine only (an SPI controller talks to SPI peripheral DEVICES — sensors/flash — within one machine, or SPI<->radio). So a wired MCU-to-MCU SPI link as M11 AC#2 / PRD 11 literally say ('master + sensor MCUs over SPI') is NOT directly modellable in Renode. DECISION REQUIRED (PRD-level, user's call) before M11 codegen: re-scope AC#2's interconnect to a UART hub (the supported wired multi-MCU bus, matching AC#2's flexible 'shared interconnect' wording) or CAN hub, vs. insisting on SPI (which would need a non-trivial custom SPI-bridge peripheral or modelling one MCU's SPI master against a shared SPI-slave device the other polls — awkward and unproven). REMAINING M11 WORK once the interconnect is chosen: (1) EMPIRICAL proof with OUR firmware — 2x (or 3x) STM32H743 machines + the chosen hub, one transmits, others receive, headless capture (mirror tests/renode/uart-smoke + the multi-node .resc pattern); (2) DEEP codegen (fresh context): lift the embedded-pattern single-worker guard (backends/embedded-pattern/src/lib.rs emit()), lower Event::Push/Wait -> cross-MCU transport over the chosen hub, Event::Sync -> shim.irq_barrier across MCUs; (3) prerequisites TASK-0192 (bring 14-hearing-aid/embedded_multimcu into lower/link/ACFG matrix) + TASK-0054.01 (per-frame peripheral kernels). Anchors: scripts/multi-node/*.resc, src/.../Peripherals/UART/UARTHub.cs, src/Renode/Connectors/GPIOConnector.cs.
