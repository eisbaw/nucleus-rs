## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Sibling prereq to TASK-0049.03 (which landed per-cell ALGO selection via resolve_algo_path honouring 'schedule for'). The e2e harness STILL hardcodes ex_dir/kernels.rs at both cell sites (e2e/src/main.rs run_cell ~1390 and check_cell_determinism ~1880). example 14's embedded_multimcu_sync schedule needs kernels.embedded.rs (the no_std/stateful kernels variant), NOT kernels.rs. So even with algo selection solved, an embedded cell promoted from [[skip]] would compile against the WRONG kernels file. This is the structurally-identical untouched SILENT SIBLING of the algo-selection fix: resolve_algo_path covered algo only. Needs either (a) a per-cell 'kernels = ...' override in e2e-matrix.toml, or (b) a convention deriving the kernels filename from the algo/sched (e.g. kernels.embedded.rs paired with prog.embedded.algo.nuc). Required before ANY embedded_multimcu cell can be promoted from [[skip]], alongside TASK-0049.02 (stateful kernels) + TASK-0049.05 (BIN guard lift + Renode multi-MCU).

## Implementation Plan (cycle, IMPLEMENTER)

DESIGN CHOICE: option (b) convention-derivation (RECOMMENDED minimal), NOT (a) explicit toml field.
Rationale: mirrors how TASK-0049.03 derived algo from the sched's own 'schedule for' declaration — no schema/plumbing churn. Empirically verified the convention is universal across all 18 examples (nuc-nucleus/examples/): the ONLY non-default pairing is example 14 prog.embedded.algo.nuc <-> kernels.embedded.rs; all 17 others use prog.algo.nuc <-> kernels.rs. An explicit toml field would add schema + thread-through at two sites for a one-example need; the downstream fixture-existence check already guards correctness if the convention is ever violated, so the convention carries no silent-wrong risk.

DERIVATION RULE (pure fn of algo_path.file_name()):
  - take algo_path.file_name() (robust to the '..'-bearing resolved path);
  - if the filename ends with '.algo.nuc' AND the stem (minus that suffix) starts with 'prog', the variant = remainder after 'prog' (e.g. '' or '.embedded');
  - kernels filename = format!("kernels{variant}.rs")  ->  'kernels.rs' / 'kernels.embedded.rs';
  - FALLBACK to 'kernels.rs' for any filename NOT matching prog[.variant].algo.nuc (historical universal default; fixture-existence check still guards).
  Pure-filename derivation, no fail-loud (unlike resolve_algo_path) — a non-matching algo defaults to kernels.rs, the historical hardcode, so no live cell can regress.

WIRE at BOTH sites (run_cell ~1402, check_cell_determinism ~1901): replace ex_dir.join("kernels.rs") with ex_dir.join(kernels_filename_for_algo(&algo)); remove the two TODO(TASK-0049.08) blocks.

TESTS (load-bearing — e2e totals don't move): in e2e/src/tests.rs, pure-filename tests:
  1. prog.algo.nuc -> kernels.rs
  2. prog.embedded.algo.nuc -> kernels.embedded.rs (THE BITE)
  3. unconventional (weird.nuc / foo.algo.nuc) -> kernels.rs fallback
  + a '..'-bearing synthetic path to exercise .file_name() robustness.

SCOPE: harness fixture-selection only. NO [[skip]]/[[required]] edits, NO embedded cell promotion (still needs TASK-0049.02 + TASK-0049.05). e2e MUST stay 308/246/0/62/0.
