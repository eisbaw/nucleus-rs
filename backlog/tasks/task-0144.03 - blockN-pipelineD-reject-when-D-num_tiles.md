## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-0144 Stage 3 follow-up: block=N + pipeline=D where D >= num_tiles is meaningless (no parallel tiles to keep in flight). Today the block+pipeline combination is unconditionally rejected at sched-lower via BlockPipelineConflict (TASK-0215), so this finer-grained rejection only becomes relevant if/when block+pipeline is unblocked. Needs the loop bound (num_tiles = ceil((HI-LO)/N)), which is on the ACFG, not the schedule alone — so the validation pass runs after ACFG injection, not at sched-lower.
