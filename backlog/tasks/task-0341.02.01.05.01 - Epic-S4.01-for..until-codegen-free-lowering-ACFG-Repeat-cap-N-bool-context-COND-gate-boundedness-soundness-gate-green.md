## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
IMPLEMENTATION PLAN (cycle-260):
DESIGN CHOICE: A (field) over B (sidecar). break_cond: Option<IrExpr> added to ACFGNode::Repeat (acfg/types.rs). Rationale: the existing block_tag payload-field docstring (types.rs ~435-445) explicitly chose a per-occurrence payload field over a per-IterVar sidecar BECAUSE block_transform reuses one IterVar across strip-mined passes, conflating loop occurrences — the identical conflation defeats a break-cond sidecar keyed by iter_var, and there is no stable per-loop-id substrate today. A field is silent-sibling-SAFE (compiler forces every construct site + the exhaustive petri_to_events match forces a future consume site); a sidecar is silent-sibling-DANGEROUS (a transform rebuilding a loop silently drops the key). Cost: ~38 construct sites set break_cond: None; only acfg/build.rs sets Some. Mechanical, compiler-checked.
STEPS:
1. acfg/types.rs: add break_cond: Option<IrExpr> to ACFGNode::Repeat with serde(default) (old wire payload -> None) + docstring (analysis-invisible to the Net).
2. acfg_to_petri.rs Repeat arm already { range, body, .. } — add a comment that break_cond is intentionally ignored (analysis-invisible).
3. acfg/build.rs: replace the UntilLoopUnsupported reject with real lowering. Require until COND to be IrExpr::Compare; non-Compare -> NEW typed BuildAcfgError::UntilCondNotComparison; a Compare lowers to Repeat { break_cond: Some(cond) }. Plain for sets break_cond: None.
4. Sweep all ~38 construct sites: break_cond: None.
5. petri_to_events.rs exhaustive Repeat match: add break_cond binding (ignored for now; .05.04 consumes it).
6. Tests: positive integration (for..until lowers, builds ACFG, builds Petri, unrolls to N, boundedness/net_soundness/deadlock gates Ok) + negative (non-Compare COND -> UntilCondNotComparison).
BOOL-CONTEXT GATE DECISION: pragmatic — until-COND MUST be IrExpr::Compare (the only bool-valued IrExpr today). Not a full bool type system; file a follow-up if warranted. Honest: it is "until-COND must be a relational comparison" = exactly the convergence shape.
