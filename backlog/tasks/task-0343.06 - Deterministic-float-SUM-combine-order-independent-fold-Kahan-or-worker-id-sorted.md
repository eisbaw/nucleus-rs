## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-0343.02 ADMITTED float min/max (order-independent) and REJECTED float sum (IEEE-754 addition is non-associative -> per-backend reduction orders diverge -> violates PRD 10.1 bit-identity). This task is the deferred path to make float SUM admissible by forcing a deterministic, order-independent reduction: either (a) a fixed worker-id-sorted sequential fold of the partials on the host (cross-backend stable, the simplest), or (b) a user-declared Kahan/compensated-summation kernel. The combine_form_for_scalar float-sum reject message (backend-common/src/multi_worker_walker/wait.rs) points here. Prove with a float-sum reduction-to-array bit-identical across 7 backends. Depends on the float min/max machinery from TASK-0343.02 (Done).
