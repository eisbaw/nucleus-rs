## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-0023.03 Stage 3 — depends on Stage 2 (the comparator). Adds per-cell perf gating to the manifest:

- [ ] `[[required]]` and `[[skip]]` entries in `nuc-nucleus/e2e-matrix.toml` accept an optional `perf_threshold_pct = N` (default = None = no gate).
- [ ] When `--baseline` is set, cells with a threshold whose delta exceeds N% are flagged as REGRESSION rows in the delta table.
- [ ] Exit-code semantics: a regression on a `[[required]]` cell with a threshold = HARD FAIL (non-zero exit). Skip-row regressions are informational.
- [ ] The matrix-toml deserializer (`Matrix` / `RequiredEntry`) needs the optional field plumbed in. Default-None preserves byte-identical bare-run behaviour.
- [ ] Unit tests: a matrix entry with threshold=50, baseline=200ms, current=350ms (75% slower) MUST fail; current=250ms (25% slower) MUST pass.

Out of scope: absolute-millis thresholds (relative-pct only for the first cut; absolute can be a follow-on if needed). Determinism-mode (separate followup).

Stage 1 (cycle-54) already lands the JSON schema and writer; Stage 2 is the comparator. Stage 3 is the gate.
