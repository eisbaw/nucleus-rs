## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-0144 Stage 3 follow-up: vectorize=M and block=N on the same loop where the vector width and tile size disagree should be rejected at compile time. Today both are accepted in isolation but their interaction is not validated. Likely rule: vectorize width must divide block size (similar to TASK-0144 Stage 2's unroll∤block rule). Needs a new SchedLowerErrorKind variant + matching negative test.
