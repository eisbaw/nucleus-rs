## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Root cause (confirmed by reproduction on clean master + driver build): the structural accumulator detector backend_common::multi_worker_walker::collect_accumulate_waits classifies any data symbol with >=2 whole-array Waits on one worker as an overlapping-write accumulator (element-wise sum). ex14 (14-hearing-aid embedded_multimcu_sync) produces mic_in once on fe and reads it via TWO kernels (denoise + mix2) on dsp -> 2 whole-array Waits on dsp, both src=fe. That is a single-producer/multi-consumer fan-OUT-read, not a multi-producer fan-IN that needs summing. The TASK-0343.03 driver cross-check (check_accumulator_consistency) correctly FAILS LOUD (mic_in is not LHS-in-RHS) instead of silently summing -- so this is a false-reject, not a miscompile. embedded-pattern does NOT call collect_accumulate_waits (it emits blocking shim Push/Wait); the ONLY thing rejecting ex14 is the driver-level cross-check.

Fix (root cause, not workaround): the correct structural discriminator for a sum fan-in is >=2 DISTINCT PRODUCER workers, not >=2 Waits. Event::Wait carries src:WorkerId. Refine collect_accumulate_waits: (1) walk_waits captures (SeqTag, src) per Wait; (2) the predicate additionally requires the whole-array Waits to come from >=2 distinct src. This excludes ex14 mic_in (1 distinct src -> whole-array assign, idempotent same-value receive = correct) while preserving 08-histogram/distributed (4 distinct producers -> still accumulate) AND preserving the cross-check fail-loud for a genuine multi-producer fan-in that is not LHS-in-RHS.

Safety: all existing positive classifier tests (whole_array_classifier.rs two_waits_with_tile, wait_assign_accumulate.rs histogram) already use DISTINCT src (WorkerId(i+1)), so they stay green. No tier-1 shipping schedule has a single-producer/multi-consumer whole-array shape (the cross-check is a no-op on the whole e2e matrix), so e2e totals must be UNCHANGED -- that is the safety check. Add a new same-src regression pin. Update the 3 docstrings (collect_accumulate_waits / walk_waits / check_accumulator_consistency) to reflect the distinct-producer refinement (no doc-lies). Gate: just build+clippy+test+test-release+e2e (default shell) THEN check-embedded ex14 under nix develop .#embedded.
