## Description

TASK-0343 cycle 189 detects the overlapping-write accumulator pattern PURELY STRUCTURALLY at the codegen layer: per-worker, group Waits by data; for each data with N>=2 Waits where every pair_tile is whole-array, classify all as accumulate (collect_accumulate_waits in backend-common/src/multi_worker_walker/collect.rs).

For every shipped schedule today (08-histogram/distributed is the load-bearing case), the structural pattern is equivalent to the algorithm-level accumulator pattern (LHS appears in RHS: 'histogram[b] <-- bin_inc(histogram[b], ...)'). But an exotic schedule that emits multiple whole-array pushes for non-accumulator semantics (no obvious example today) would be silently mis-combined as element-wise sum.

Scope: add a cross-check to collect_accumulate_waits that consults the algorithm-IR for the LHS-appears-in-RHS shape on the destination data symbol BEFORE classifying as accumulate. The check is a tightening (no shipped cell affected); reject (typed EmitError) if the structural pattern fires but the algorithm-level shape is not accumulator.
