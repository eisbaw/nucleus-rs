## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-0054.01 part 2 (deferred deep-codegen). The per-frame embedded algorithm (nuc-nucleus/examples/14-hearing-aid/prog.embedded.algo.nuc, landed TASK-0054.01) declares fe_capture/rf_receive/fe_emit/rf_transmit but has NO Rust bodies. This task writes a stateful kernels.rs (or kernels.embedded.rs): fe_capture/rf_receive track a per-kernel call cursor (AtomicUsize) reading frame[cursor] from canned bins; fe_emit/rf_transmit write frame[cursor] to accumulating buffers flushed on Drop (tier-1) or at program-exit (tier-3 bin, no Drop on a spinning firmware — see TASK-0048.08 note). SAFE ONLY in single-process M11/Renode mode: a shared call cursor breaks the multi-process tier-1 backends (mp-tcp-bufsync gives each process its own kernels.rs instance with no shared cursor). Front-end (sched_lower/link/acfg) already admits the schedule (TASK-0192). Depends on: e2e-harness algo selection (sibling task) so the build can pick prog.embedded.algo.nuc.
